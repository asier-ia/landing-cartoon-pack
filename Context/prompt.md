Create a stunning and interactive landing page for a cookie shop ("Galletería") launching a new pack of 3 cookie flavors. The main goal of the page is for users to vote for their favorite new flavor. All text on the page must be in Spanish.

AESTHETIC & DESIGN SYSTEM:
- Style: 1930s rubber hose cartoon, "Cuphead" style, vintage 1950s milkshake diner.
- Vibe: Super cute, nostalgic, bouncy, and fun.
- Backgrounds: Use vintage cream/off-white (e.g., bg-[#FDF6E3]) to simulate old celluloid paper. Add subtle grain or noise if possible.
- Borders & Shadows: Heavy, bold black outlines (border-4 border-black) on all cards and buttons. Use solid black retro drop shadows (e.g., shadow-[8px_8px_0px_0px_rgba(0,0,0,1)]).
- Colors: Vintage pastel and primary tones (faded reds, mustard yellows, baby blues, mint greens).
- Typography: Use a chunky, playful, and retro-looking font.

LAYOUT & SECTIONS:
1. Header: A cute, vintage-style navbar with the logo "La Galletería Animada" and a bouncing call-to-action button saying "¡Vota Ya!".
2. Hero Section: A highly stylized, bold headline announcing "¡El Gran Duelo de Sabores!". Add a playful subtitle explaining that a new 3-pack is out and users must vote for the winner. Include a decorative vintage-style badge.
3. Voting Section (The Core): Display 3 large, eye-catching cards side-by-side (or responsive stack on mobile) for the 3 new flavors (e.g., "Choco-Loca", "Fresa Mágica", "Vainilla Retro").
   - Each card must have a distinct vintage color background.
   - Give each card heavy black borders and a solid black shadow.
   - Inside each card: A placeholder for a cute cartoon cookie character, the flavor name, a short description, and a big, bouncy "¡Votar por este!" button.
   - Add hover effects to the cards and buttons so they feel alive (e.g., hover:-translate-y-2, hover:shadow-[12px_12px_0px_0px_rgba(0,0,0,1)]).
4. Progress/Results Section: A vintage-styled progress bar or tally board showing the current voting percentages for each flavor.
5. Footer: A classic vintage cartoon end screen style ("¡Eso es todo, amigos!") with social media links styled as retro icons.

INTERACTIVITY & ANIMATIONS:
- Use framer-motion to make elements pop and bounce in when scrolling (spring animations).
- Buttons should have a satisfying "press" effect (active:translate-y-1 active:shadow-none).

Make the UI fully responsive, utilizing Tailwind CSS and shadcn/ui components creatively modified to fit this extreme retro cartoon aesthetic.
